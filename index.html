ช่องทาง รายได้รวม ยกเลิก รายได้สุทธิ ค่าคอมฯ แพลตฟอร์ม
(Shopee/Lazada/TikTok)		 ค่าแพ็ค Packhai รายได้หลังหักทั้งหมด

⏳ รอข้อมูลเพิ่มเติมจาก Packhai — ตัวเลข "ค่าธรรมเนียม" ยังไม่สมบูรณ์ 100%

  1. ค่าแพ็ค/ค่าบับเบิ้ล/ค่ากล่องของ Packhai เอง — ยังไม่มี API ให้ดึง เห็นได้แค่ในหน้าเว็บ การเงิน > ประวัติเครดิต กำลังรอ Packhai ตอบว่าจะเปิด endpoint ให้ได้ไหม
  2. ค่าคอมมิชชั่นของ Lazada และ TikTok — ยังไม่มี endpoint ดึงยอดสุทธิแบบเดียวกับ escrow ของ Shopee กำลังรอถามว่า endpoint แบบ proxy ที่มีอยู่ใช้ดึงข้อมูลนี้ได้ไหม

ตารางด้านบนแยกไว้ให้แล้วเป็น 2 คอลัมน์: "ค่าคอมฯ แพลตฟอร์ม" (มีข้อมูลจริงเฉพาะ Shopee) และ "ค่าแพ็ค Packhai" (ยังไม่มีข้อมูลเลยสักช่องทาง รอ Packhai เปิด API ก่อน) — ดูป้าย "มีข้อมูล"/"รอข้อมูล" ในแต่ละแถวประกอบ เมื่อได้คำตอบจาก Packhai แล้ว ตัวเลขคอลัมน์ค่าแพ็คจะขึ้นเองโดยไม่ต้องแก้หน้านี้อีก
